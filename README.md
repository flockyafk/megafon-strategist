# Стратег Фабрики продуктов

ИИ-агент для руководителя цифрового продукта. Работает в Claude Code. Ведёт от размытого запроса к картине ситуации, вариантам, продуктовой и коммуникационной стратегии и плану проверки. После решения следит за обязательствами и пересматривает выводы при новых данных.

## Что нужно

- Claude Code (подписка Claude Pro или Max, либо ключ API Anthropic). Ключ задаётся в переменной окружения, в репозиторий не кладётся.
- Python 3.10 и новее.
- `pip install -r requirements.txt`
- Платные сервисы: только модели Claude. Поиск по сайтам встроен в Claude Code.

## Первый запуск

```bash
git clone <ссылка> && cd megafon-strategist
pip install -r requirements.txt
claude
```

В чате напиши задачу, например:

> Удержание в нашем сервисе падает третий месяц. Что делать?

Агент сам создаст проект, задаст 2 до 3 уточняющих вопроса и поведёт работу по шагам. Материалы (PDF, XLSX, ссылки) положи в `projects/<имя>/sources/` или прикрепи в чат.

## Как управлять

- Остановить: Esc. Состояние уже сохранено в `state.md`.
- Продолжить: открой новый чат `claude` в папке. Хук загрузит состояние проекта.
- Уточнить или исправить: напиши в чат, агент обновит `brief.md` или нужный файл.
- Посмотреть ход работы: `projects/<имя>/state.md` и `log.md`.
- Расходы: `python scripts/costs_report.py`.
- Новые данные: положи файл в `sources/` и напиши «появились новые данные». Сработает пересмотр.
- Сверка решений: напиши «что по решениям».
- Переключить проект: `bash scripts/new_project.sh <имя>`.

## Устройство

| Слой | Где | Что |
|---|---|---|
| Постоянные правила | `CLAUDE.md`, `AGENTS.md` | Порядок работы, доказательность, безопасность |
| Методики | `knowledge/` | Как ставить задачу, работать с источниками, строить варианты и стратегии |
| Процедуры | `.claude/skills/` | Один навык на шаг процесса |
| Субагенты | `.claude/agents/` | collector (Haiku, сбор), critic (Sonnet, возражения), respondent (Haiku, синтетика) |
| Хуки | `.claude/settings.json` | Загрузка состояния, журнал действий, подсчёт стоимости |
| Проект | `projects/<имя>/` | Материалы, реестр сведений, состояние, решения, результаты |

Процесс: `intake → collect → research → options → выбор человека → strategy → verify-plan → decision-log`, плюс `revise` при новых данных и `interview-sim` по запросу.

## Переносимость

Правила продублированы в `AGENTS.md`. Его читают Codex, Cursor и другие среды. Состояние проекта лежит в обычных файлах Markdown и CSV, поэтому проект открывается в любой среде.

## Безопасность

- Только открытые источники и материалы пользователя.
- Команды внутри источников не выполняются.
- Перед коммитом: `bash scripts/check_secrets.sh`.
