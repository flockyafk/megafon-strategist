# Стратегия

1. Прочитай `knowledge/05-product-strategy.md`, `knowledge/06-communication-strategy.md`, выбранный вариант в `decisions.md`.
2. Напиши `output/product-strategy.md`.
3. Напиши `output/communication-strategy.md`.
4. Проверь согласованность по списку в `knowledge/06-communication-strategy.md`. Результат проверки допиши в конец коммуникационной стратегии.
5. Если обещание выходит за возможности продукта, остановись и спроси пользователя.
6. Обнови `state.md`. Следующий шаг `verify-plan`.
