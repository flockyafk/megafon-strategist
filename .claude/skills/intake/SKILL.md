# Постановка задачи

1. Прочитай `knowledge/01-framing.md`.
2. Прочитай запрос пользователя и всё, что лежит в `projects/<имя>/sources/`.
3. Заполни черновик `projects/<имя>/brief.md` по шаблону. Что можно предположить, предположи и пометь `[допущение]`.
4. Задай пользователю не больше 3 вопросов, без которых нельзя идти дальше. Предложи варианты ответа.
5. После ответа обнови `brief.md`. Сформулируй решение как выбор между исходами.
6. Обнови `state.md`: шаг `intake` завершён, следующий `collect`.

Не начинай исследование, пока не ясны вопрос, цель и получатель.
