# План проверки

1. Прочитай `knowledge/07-verification.md` и обе стратегии.
2. Напиши `output/verification.md`: таблица по каждой ставке.
3. Собери `output/report.md` для руководителя:
   - Рекомендация в 3 строках.
   - Картина ситуации кратко.
   - Варианты и почему выбран этот.
   - Продуктовая стратегия.
   - Коммуникационная стратегия.
   - План проверки.
   - Пробелы и риски.
   - Сколько стоила работа: `python scripts/costs_report.py`.
4. Обнови `state.md`. Следующий шаг `decision-log`.
